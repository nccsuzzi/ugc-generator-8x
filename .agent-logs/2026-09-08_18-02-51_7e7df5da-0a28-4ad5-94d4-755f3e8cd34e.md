# Build: UGC Video Generator — Chat App

Build a polished, production-quality MVP for this coding assignment:

> **A web app with a chat interface. One input box, a message thread, nothing more than that to start.**
>
> Someone sends:
>
> “I'm building CalAI, a calorie-tracking app. Here's the site: calai.app”
>
> The app should understand what the product is, read the URL/content, assemble a short UGC-style video, and return the final video directly inside the same chat.

>
