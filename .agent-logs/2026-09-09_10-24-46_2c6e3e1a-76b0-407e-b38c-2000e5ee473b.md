### 3. Docker Compose Version (Multi-Service Stack)

The project includes [docker-compose.yml](file:///Users/usman/Developement/ugc-generator-8x/docker-compose.yml) which spins up PostgreSQL, the FastAPI backend, and the Next.js frontend automatically with container networking configured.

#### `docker-compose.yml` Definition
```yaml

    image: postgres:16-alpine
    container_name: ugc_postgres
    restart: unless-stopped
    environment:
      POSTGRES_USER: postgres
      POSTGRES_PASSWORD: password
      POSTGRES_DB: ugc_generator
    ports:
      - "5432:5432"
    volumes:
      - postgres_data:/var/lib/postgresql/data
    healthcheck:
      test: ["CMD-SHELL", "pg_isready -U postgres"]
      interval: 5s
      timeout: 5s
      retries: 5

  backend:
    build:
      context: ./backend
      dockerfile: Dockerfile
    container_name: ugc_backend
    restart: unless-stopped
    ports:
      - "8000:8000"
    environment:
      DATABASE_URL: postgresql://postgres:password@postgres:5432/ugc_generator
      GROQ_API_KEY: ${GROQ_API_KEY:-}
      GROQ_MODEL: ${GROQ_MODEL:-openai/gpt-oss-120b}
      JINA_API_KEY: ${JINA_API_KEY:-}
      GIPHY_API_KEY: ${GIPHY_API_KEY:-}
      PEXELS_API_KEY: ${PEXELS_API_KEY:-}
      EPIDEMIC_API_KEY: ${EPIDEMIC_API_KEY:-}
      EPIDEMIC_TIER: ${EPIDEMIC_TIER:-PROTOTYPE}
      EPIDEMIC_PARTNER_USER_ID: ${EPIDEMIC_PARTNER_USER_ID:-ugc-generator-admin}
    depends_on:
      postgres:
        condition: service_healthy

  frontend:
    build:
      context: ./frontend
      dockerfile: Dockerfile
    container_name: ugc_frontend
    restart: unless-stopped
    ports:
      - "3000:3000"
    environment:
      NEXT_PUBLIC_API_URL: http://localhost:8000
    depends_on:
      - backend

volumes:
  postgres_data:
```

### 5. Known Gotchas & Things to Watch Out For

1. **System-Level Binaries (`ffmpeg` and `ffprobe`)**:
   - The video rendering engine relies on `ffmpeg` and `ffprobe` binaries.
   - If running locally outside Docker, FFmpeg must be installed manually (`brew install ffmpeg` on macOS, `apt-get install ffmpeg` on Linux).
   - Inside the container, Debian package `ffmpeg` supplies both `/usr/bin/ffmpeg` and `/usr/bin/ffprobe`.

2. **TrueType Fonts for PIL Text Overlays**:
   - The subtitle/hook text overlay renderer in [ffmpeg_service.py](file:///Users/usman/Developement/ugc-generator-8x/backend/app/services/ffmpeg_service.py#L368-L382) searches Linux font paths: `/usr/share/fonts/truetype/dejavu/DejaVuSans-Bold.ttf`.
   - Minimal Debian slim base images (`python:3.11-slim`) **do not include any TrueType fonts by default**. The `fonts-dejavu-core` package must be installed; otherwise Pillow falls back to an unscalable 10px default bitmap font, resulting in illegible text overlays on 1080x1920 videos.

3. **Context Bloat Without `.dockerignore`**:
   - Host `frontend/node_modules` (500MB+) and `frontend/.next` should never be copied into the container context during `docker build`.
   - The [.dockerignore](file:///Users/usman/Developement/ugc-generator-8x/.dockerignore) and [frontend/.dockerignore](file:///Users/usman/Developement/ugc-generator-8x/frontend/.dockerignore) files exclude `node_modules`, `.next`, `.venv`, and `.git`, reducing context transfer time from ~585MB to ~2KB.

4. **Next.js Multi-Stage Build & `devDependencies`**:
   - In Next.js with TypeScript and Tailwind CSS, tools like `typescript`, `tailwindcss`, and `@types/react` reside in `devDependencies`.
   - Running `npm ci --omit=dev` before `npm run build` will cause `next build` to fail immediately. Multi-stage builds must install all dependencies in the builder stage and only prune `--omit=dev` in the final runner stage.

5. **Host vs Container Architecture**:
   - Copying host `node_modules` built on macOS (Darwin arm64) into Alpine Linux (`node:22-alpine` musl) causes native binding errors such as `Cannot find module '../lightningcss.linux-arm64-musl.node'`. Keeping clean container-internal installs via `npm ci` avoids this.
